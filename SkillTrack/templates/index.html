How to read this report

Snapshot-based tracking: SkillTrack checks each public profile when you run the report. It does not monitor profiles continuously in the background, and continuous live tracking is not necessary for a campaign progress tracker. Upload the roster and run another check whenever you want an updated snapshot.

Private profiles: A profile identified as private by the public page, access response, or an explicit CSV reference note is labelled “Private profile”. The verification note identifies when the CSV supplied that information. Its badge count is left blank and excluded from averages; it is never treated as zero. The student can make the profile public and you can recheck it later.

Only live verification results should be used to assess campaign progress. Demo mode uses fictional sample counts. SkillTrack is an independent project and is not affiliated with Google.
